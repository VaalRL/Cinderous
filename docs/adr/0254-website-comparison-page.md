# 0254. 官網比較頁：與 Signal／LINE／WhatsApp 的誠實比較表

- 狀態：已接受
- 日期：2026-07-28
- 相關文件：ADR-0235（SEO/GEO）、ADR-0246（enterprise 頁同款前例）、ADR-0245（FS 硬閘：審計前不宣稱）、ADR-0166（商標風險盤點）、`apps/website/`

## 背景與問題

使用者要求官網新增與主流產品（LINE／WhatsApp／Signal）的比較表。決策點：放哪裡、以及是否包含對我方不利的比較維度。

## 考量的選項

- **位置**：(a) 獨立「比較」頁（採納——自有 URL/title/meta，吃「X vs Y 比較」高意圖搜尋，符合 ADR-0235 的每頁預渲染架構）；(b) 首頁區塊（曝光高但 SEO 集中同頁）；(c) 兩者都做（工多）。
- **誠實列**：(a) 保留對我方不利的列（採納）；(b) 拿掉 FS 列；(c) 只列優勢。

## 決策

1. **獨立 `compare` view**（照 ADR-0246 enterprise 模式）：`routes.ts` VIEWS＋`seo.ts` 獨立 title/description＋nav「比較」＋雙語預渲染／sitemap／hreflang 自動生效（12→14 頁）。
2. **十列比較**（Cinderous／Signal／LINE／WhatsApp）：手機號碼、預設 E2E、元資料、開源、伺服器架構、訊息存放、營利模式、平台停權、**前向保密**、**功能成熟度**。文案全進 `copy.ts`（SSOT，`cp_*` 雙語）。
3. **保留誠實列**：FS 列 Cinderous 格＝「開發中——外部審計完成前不對外宣稱」（承認沒有≠宣稱有，符合 ADR-0245 硬閘，**測試鎖住不得為 ✓**、Signal 誠實給 ✓）；成熟度列自承開發中。誠實表比全勝表可信。
4. **防呆**：只用文字名稱不用第三方 logo（商標）；表尾商標聲明＋資料時間（截至 2026-07）；措辭避免絕對化（「大幅隱藏」非「完全隱藏」——relay 可見 presence 是我方文件誠實記載的）；LINE E2E 標「部分（Letter Sealing）」。Cinderous 欄以主色淡染突顯、`th scope` 齊備（無障礙）。

## 理由

獨立頁讓「Signal vs LINE 比較」這類高意圖查詢有專屬著陸點（每頁自有 meta/canonical 是既有架構的免費紅利）；比較內容基於公開資訊且承認弱項，法律與信任風險皆最低。FS 格用測試鎖住，防未來文案迭代誤把「開發中」改成 ✓ 而違反審計硬閘。

## 後果

- **正面**：高意圖 SEO 著陸點；使用者一眼看懂差異；誠實框架與專案透明度立場一致。
- **負面 / 已知殘餘風險**：比較資訊會過時（表尾已標資料時間；競品重大變更時需人工更新）；nav 增至 7 項（窄螢幕靠既有 wrap 佈局）。
- **後續行動 / 待辦**：競品資訊年度複查（下次 2027-07 或重大新聞時）；首頁可考慮加一行導流連結（未做）。
