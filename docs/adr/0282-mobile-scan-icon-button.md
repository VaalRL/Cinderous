# ADR-0282：行動端掃描鈕改為圖示鈕，動作圖示幾何進 theme

- 狀態：已接受
- 日期：2026-07-29
- 相關：ADR-0095（訊息狀態圖示幾何進 theme 的先例）、ADR-0280（行動端 QR 加好友）、ADR-0281（掃描格式修正）

## 脈絡

ADR-0280 的掃描入口是一顆**整列寬的文字鈕**「掃描 QR」，單獨佔一行擺在加好友面板中段。
兩個問題：

- 面板已經有「複製」「顯示 QR」兩顆文字鈕；再加一顆文字鈕，三顆長得一樣但做的事差很多。
- 掃描其實是「**另一種輸入方式**」——它跟下面那個「貼上 npub」的輸入欄是同一件事的兩條路，
  卻被拆到不同列。

## 決策

### 1. 掃描鈕改為圖示鈕，並移到貼上欄同列

版面從

```
[ 掃描 QR                    ]
[ 貼上 npub…            ][新增]
```

變成

```
[ 貼上 npub…      ][⛶][新增]
```

圖示鈕沒有文字標籤，因此**必須帶 `aria-label`**（用既有的 `qr_scan` 文案）——
沒有文字的按鈕對讀螢幕的人等於一塊空白。這條有紅字測試鎖住。

### 2. 圖示幾何放 `@cinderous/theme` 的 `ACTION_ICONS`

比照 ADR-0095 的 `MSG_STATUS_ICONS`：**幾何與規格放 theme，渲染由各前端自己做**
（行動端用 react-native-svg 的 `ActionIcon`，與 `MsgStatusIcon` 同一種分工）。
桌面日後若要同一顆圖示，不必再畫一次。

圖案是**四個取景角＋中央掃描線**，刻意不畫成完整的 QR 方格——那與旁邊的
「顯示我的 QR」看起來會太像。取景框＋掃描線是相機取景的通用語彙，
一眼可辨「這是去掃別人的」。

## 後果

**正面**

- 加好友面板少一列，且「貼上／掃描」兩條輸入路徑在視覺上並列。
- 三顆功能不同的鈕不再長得一樣。
- 動作圖示有了跨前端的擺放位置，下一顆不必再決定一次。

**負面／代價**

- 圖示沒有文字，第一次見到的人可能要按一下才知道是什麼。以 `aria-label` 與
  取景框這個通用語彙緩解，但這確實是文字換空間的取捨。
- 掃描進行中的預覽仍是獨立一區（圖示鈕在掃描時隱藏）——版面會跳動一次。
  可接受：掃描是短暫的模態狀態。

**待辦**

- 實機驗收：圖示在淺／深色主題下都看得清楚；點擊區夠大（目前 padding 6/8 ＋ 20px 圖示 ≒ 32×36）。
