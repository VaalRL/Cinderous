# 0270. 右欄分頁樣式：固定高度、選中改填底（去除底線指示器）

- 狀態：已接受
- 日期：2026-07-28
- 相關文件：ADR-0079（三欄佈局右欄）、ADR-0183（行動端輔助面板）
- 補記：本 ADR 於決策落地時漏建檔（程式註解與 commit 已引用 ADR-0270），2026-07-29 補寫。

## 背景與問題

使用者回報右欄分頁（對話串／成員／媒體／便條／行程／資訊）兩個問題：

1. **切換不同分頁時高度會跳**——選中態 `.daux__tab.on { font-weight: 600 }` 讓文字變寬，
   在窄的右欄裡造成換行，該分頁因此變高，整條分頁列高度隨選中對象改變。
2. **選中態的主色底線指示器「AI 味很重」**——Material Design 的招牌樣式，與本專案
   刻意經營的懷舊即時通視覺不合。

## 決策

1. **固定分頁高度**：`height: 34px` ＋ `white-space: nowrap` ＋ flex 置中；**選中不變字重**
   （移除 `font-weight`）。任何分頁被選中時整條分頁列高度都一致，不再 reflow。
2. **選中指示改填底**：`background: var(--surface2)` ＋ 主色文字，**移除 `border-bottom` 主色底線**。
3. **回歸鎖**：`msn-layout.test.ts` 讀 CSS 斷言固定高度、nowrap、選中不含 `font-weight` 與
   `border-bottom`、且含填底——防日後被「改回熟悉的樣式」而無聲回歸。

## 理由

高度跳動的根因是字重而非字數，固定高度＋不換行＋不變字重是直接對症。填底在窄欄比底線更清楚
（底線只有 2px，在 6 個分頁擠一排時辨識度低），且脫離 Material 語彙、貼近專案既有的
chip／視窗標題列語言。

## 後果

- **正面**：分頁列高度恆定；選中辨識度提升；視覺語彙與專案一致。
- **負面 / 已知殘餘風險**：分頁文字過長時會被裁切（nowrap＋overflow hidden）而非換行——
  現有六個分頁在最窄寬度下實測可容納；日後若新增更長的分頁名需重新檢視。
