# 0415. 沒在用的身分的新訊息：預設「離開期間摘要」，設定裡可開「背景收件」

- 狀態：**已接受（Accepted，2026-11-12）**——使用者 2026-11-12 選「B＋C，預設 C、設定中可開 B；兩個身分連同一座中繼站允許、不另外警告」
- 日期：2026-11-12
- 相關文件：**0045**（多身分、一次一個作用中；本文是它留下的「同時在線」後續）、0241（分片）、0245／0365（前向保密 EK）、0107（自封副本）、0109（中繼流量）、0217（通知開關）

## 背景與問題

ADR-0045 讓同一個 App 放好幾個身分，但一次只連一個。切換＝斷線、重載、用另一個身分重連。
沒在用的身分收不到即時訊息、也不會跳通知；訊息不會丟，切回去時才補收。

「同時在線」是 ADR-0045 留下的後續。動工前要先決定代價：

1. **隱私**：兩個身分從同一個 IP、同一刻連線、同步斷線，中繼站（尤其兩個身分用同一座時）很容易把它們關聯成同一個人。
2. **企業**：用個人身分時跳出工作訊息的內容，等於工作內容出現在個人畫面上。
3. **成本**：每多一個在線身分，打到中繼站的請求就多一份（ADR-0109）；手機還有耗電。

## 考量的選項

- **A. 完整同時在線**：每個身分各跑一個完整後端，背景也能收發。關聯風險最高；後端與畫面狀態要改成多實例，工程最大。
- **B. 背景收件**：沒在用的身分只掛一條只讀的收件匣訂閱，數新訊息、跳通知；要回覆得切過去。
- **C. 離開期間摘要**：不多連線；切回來時說「你離開期間收到 N 則新訊息」。

## 決策

1. **預設 C，設定裡可以打開 B。** 不做 A。
2. **B 只讀**（引擎 `InboxWatcher`）：
   - 只訂一組 filter：`{kinds:[1059], "#p":[這個身分], since: 離開時間 − 2 天}`（外層時戳有 NIP-59 抖動，同 `inboxSince`）。
   - **不發任何事件**：不送已送達回條、不發心跳、不發個人檔。對聯絡人而言這個身分仍是離線。
   - **不寫儲存**：只讀那個身分本機存的 EK（解得開前向保密的訊息）與封鎖名單。訊息留在中繼上，切回去時正式後端照常收、照常處理。
   - 數的是看得見的訊息（rumor kind 14 的文字／檔案／群訊）；回條、個人檔、行程、入職請求、自己別台裝置的副本、封鎖的人、離開前送出的都不算。分流與 `RelayChatBackend.receiveDm` 一致；解封金鑰清單與後端共用 `fsRecipientKeys`。
3. **錯開連線**：背景連線在作用中身分就緒後隨機延遲 5～30 秒才連，不跟作用中身分同一刻連上；也不發心跳，所以沒有同步的心跳節奏。
4. **通知不含寄件人與內文**：只寫「〔身分名稱〕有 N 則新訊息」，所有身分一律如此。跟隨通知總開關。
5. **兩個身分連同一座中繼站：允許，不另外警告**（使用者決定）。
6. **範圍**：
   - 只做桌面版（Tauri）。瀏覽器版沒有金鑰庫，其他身分的 nsec 不在手上；設了本機密碼的身分沒解鎖也拿不到金鑰，一律不背景收。
   - 隱藏身分（ADR-0067）不背景收。
   - 收件匣只看 home（分片模式＝自己的訊息片，ADR-0241）；公開收件中繼（ADR-0382）與搬家排水的舊站（ADR-0066）不看。
7. **C**：切換身分時記下離開時間與當時的未讀總數（`nb.away.<pubkey>`）；切回來後 60 秒內顯示多出來的未讀數（不小於 0），可手動關。B 也從這個離開時間開始數。

## 理由

- 使用者要的是「知道另一個身分有新訊息」，不是「在背景回覆」。B 用一條只讀訂閱就做到，關聯面比 A 小得多（沒有心跳、沒有回條、連線時間錯開）。
- 只讀讓 B 不必處理兩個後端搶同一份狀態（EK 推進、未讀水位、回條）的問題——正式處理永遠只有一個後端。
- 預設 C：沒打開 B 的人完全不多一條連線、不多一點關聯面，仍得到「切回去時一眼看到錯過多少」。

## 後果

- 正面：
  - 打開 B 的人不切換也知道另一個身分有新訊息。
  - 預設行為（C）零新增連線、零新增關聯面。
- 負面／已知殘餘風險：
  - **打開 B 後，兩個身分的收件匣訂閱來自同一個 IP**。錯開連線時間只減輕、不消除；兩個身分用同一座中繼站時，站方仍可能把它們關聯起來（使用者接受，決策 5）。
  - 每個背景身分多一條連線、多一個 REQ（ADR-0109 的流量）。
  - 背景身分的 EK 在 B 啟動時讀一次；B 持續期間那個身分若在別台裝置輪替 EK，新 EK 加密的訊息會解不開、不計數（切回去時正式後端照常收）。
  - 數字是近似值：別台裝置已讀掉的、或寄到公開收件中繼的，B 不知道；C 的數字是未讀的差，別台裝置讀掉的會被扣掉。
- 後續行動：
  - 手機版（Android 背景通知只處理作用中身分，ADR-0410）另議。
