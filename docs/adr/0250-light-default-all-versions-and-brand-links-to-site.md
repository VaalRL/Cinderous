# 0250. 全版本首次啟動預設淺色，且品牌字樣「Cinderous」外連官網

- 狀態：已接受
- 日期：2026-07-27
- 相關文件：ADR-0246（官網預設淺色、移除 prefers-color-scheme）、ADR-0249（三欄明暗鈕）、ADR-0064（主題色 accent，與明暗不同）、`theme.tsx`、`site.ts`（`SITE_BASE` SSOT）

## 背景與問題

1. **首次啟動的預設主題不一致**：官網（ADR-0246）與行動端（`initialTheme = "light"`）已預設淺色；但**桌面/webapp** 的 `initialTheme()` 仍讀 `prefers-color-scheme: dark` → 在系統為深色的機器上首次啟動就是深色。使用者希望「初次登入」在**所有版本**一致地是淺色。
2. **品牌字樣不能點**：app 名稱「Cinderous」（`t("appName")`）顯示在登入／解鎖／經典聯絡人視窗的標題列，是純文字；使用者希望**點擊它外連回官網**。（官網 nav 的品牌已是連往首頁的連結。）

## 考量的選項

- **主題**：(A) 維持跟隨系統深色；(B) 首次一律淺色、深色改手動（收斂官網 0246 立場）。
- **品牌連結範圍**：只做登入畫面？還是所有顯示 app 名稱處？含**原生 Tauri 標題列**嗎？
- **重用**：各處就地把 `<span>` 改 `<a>`，或抽共用元件？

## 決策

1. **主題**：桌面 `initialTheme()` **移除 `prefers-color-scheme` 分支**，首次啟動一律回 `light`（已存的使用者偏好仍優先）。至此三版本首次啟動皆淺色，深色＝使用者手動切換（本機記憶）。行動端／官網本已淺色，不需改。
2. **品牌字樣**：抽 `BrandWordmark`（SSOT）＝ app 名稱包成外連 `SITE_BASE` 的連結（新分頁、`rel="noopener noreferrer"`，比照 `SettingsPanel` 既有外連寫法）。用於 **SignIn／UnlockScreen／ContactListWindow** 的標題列——這些是「初次登入／解鎖」與經典佈局都會出現、且**非視窗拖曳把手**的地方。
3. **刻意不動原生 Tauri 標題列**：那條是 OS 視窗拖曳把手（`data-tauri-drag-region`），把標題文字變連結會與拖曳衝突、且易誤觸導覽——保留為拖曳把手。
4. **官網 nav 品牌**維持連往首頁（既有），即官網自身的「回官網」。**行動端**無 in-app 品牌字樣，無處可接。
5. 新增 i18n `brand_visitSite`（「前往官網」／「Visit website」）作為連結 tooltip。

## 理由

首次一律淺色讓跨版本體驗一致、也消除桌面在深色系統上的首開閃深色；深色仍可一鍵切換並記住，不損失功能。抽 `BrandWordmark` 消除三處重複、日後改連結/文案只一處（SSOT）。把連結放在「內容型標題列」而非「OS 拖曳把手」避開拖曳/點擊衝突，是各環境最安全的落點；「初次登入」在桌面與 webapp 都經 SignIn，故此範圍已覆蓋使用者訴求。

## 後果

- **正面**：三版本首次啟動皆淺色；登入／解鎖／經典聯絡人視窗的「Cinderous」點擊即開官網（行銷漏斗）；主題與品牌連結各收斂為單一來源。
- **負面 / 已知殘餘風險**：原生 Tauri 標題列的「Cinderous」維持不可點（拖曳把手，刻意）；因此 Tauri 三欄**登入後**無可點品牌字樣（登入畫面已有）。行動端無 in-app 品牌字樣可接。`<a target="_blank">` 於 Tauri 開啟外部連結沿用專案既有慣例（無 opener 外掛）。
- **後續行動 / 待辦**：若日後要 Tauri 登入後也能點品牌 → 需在標題列另置一個明確、非拖曳區的小連結（另議）。
