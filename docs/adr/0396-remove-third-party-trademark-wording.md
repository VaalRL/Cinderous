# 0396. 公開文件與程式碼不再以第三方商標描述產品；補上字型授權與商標聲明

- 狀態：已接受（使用者 2026-10-29：「先清理檔案就好 移除檔案中對於智慧財產權有風險的描述」；後續三項：「1. 改 2. 不用重新設計 3. 改成cinderous」）
- 日期：2026-10-29
- 相關文件：ADR-0166（商標）、ADR-0192（官網自架 Manrope 字型）、ADR-0215／0216（經典佈局）、ADR-0247（吉祥物）

## 背景與問題

公開 repo 的智慧財產權檢查（2026-10-29）沒有在歷史中找到秘密，但發現以下幾類風險：

- README、PRD、官網文案、發行說明都寫著「高度還原早期 MSN Messenger 的經典互動體驗」「經典 MSN 佈局」。MSN 是 Microsoft 的商標，這種寫法容易被解讀成與它有官方或延續關係。
- 吉祥物的說明寫「MSN buddy 藍身」，等於自己寫明造型的來源。
- 官網自架的 Manrope 字型（OFL 1.1）沒有附上授權全文，而 OFL 要求散布時附上。
- 程式註解與 ADR 裡也到處是「MSN 風」「MSN 擬真」。

## 考量的選項

- 選項 A：另開乾淨的 repo、封存舊 repo。歷史中沒有秘密，而風險內容大多還在現行檔案裡，只換 repo 不會讓它們消失。使用者決定先不做。
- 選項 B：只改對外文案（README、官網）。程式註解與 ADR 仍在公開 repo 裡，同樣看得到。
- 選項 C：所有現行檔案都改成中性用語，並補上授權與商標聲明。

## 決策

採選項 C：

1. 現行檔案不再用「MSN」描述產品或設計：
   - 中文改成「早期桌面即時通訊軟體」「經典即時通」；
   - 英文改成 “early desktop instant messengers” “classic IM”。
   - 範圍包含 README、PRD、官網文案、`docs/releases.json`、程式註解、ADR 本文與索引。
2. 吉祥物的說明改成「藍色圓身＋燭火頭」，不提來源。
3. 新增 `apps/website/src/fonts/OFL.txt`：Manrope 的 OFL 1.1 全文，取自 Google Fonts 的官方檔案。
4. README 中英文的授權段落補上：
   - 字型的授權說明；
   - 一句商標聲明：本專案與 Microsoft 或其他即時通訊軟體的廠商沒有關聯，也未獲其背書。
5. **不改的部分**：
   - 內部檔名 `msn.css`、`msn-layout.test.ts`、`msn-contrast.test.ts`：不會給使用者看到，改名要動 20 多處引用，風險低。
   - 字型堆疊裡的 “Microsoft JhengHei”、WiX 的 schema 網址、威脅情報清單裡的 `microsoft.com`：這些是技術上的正確名稱，不是在描述產品。
   - git 歷史：不改寫。
   - 功能本身（震動、音樂狀態、離線留言、浮動視窗）：這些是通用的即時通功能，不受商標保護。

## 理由

- 商標風險來自「描述方式」，不是功能。改成中性用語成本低，產品定位也不會因此說不清楚。
- 檔案全面一起改，以後新寫的內容就有一致的用語可以照著寫。

## 後果

- 正面：
  - 公開文件不再暗示與 Microsoft 有關；
  - 字型授權合規。
- 負面 / 已知殘餘風險：
  - git 歷史與舊版發行頁面仍有舊用語。
  - 吉祥物只改了文字說明，造型沒有重新設計：使用者決定不重新設計。造型是原創向量（藍色圓身＋燭火頭），沒有使用任何第三方素材。
- 後續（2026-10-29 使用者決定）：
  - GitHub repo 的描述欄位已改成「重溫早期桌面即時通的經典體驗」（`gh repo edit`），英文版同步。
  - 吉祥物不重新設計。
  - ADR-0166 建議註冊的商標由「Cinder」改成「Cinderous」：「Cinder」已有 libcinder、OpenStack Cinder 與一件審查中的美國 CINDER 商標（Class 9），「Cinderous」查無撞名。ADR-0166、ADR-0257 與索引已同步。
- 驗證：
  - `git grep MSN` 除了威脅情報資料之外沒有結果；
  - desktop、website、brand 的測試全部通過。
